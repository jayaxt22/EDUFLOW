# UI/UX Design System

The frontend is already built. Extend it, do not replace it.

## Colors
- Primary Brand (Yellow): `#FACC15` — buttons, active sidebar, brand accents.
- Success (Green): `#22C55E` — present stats, success states.
- Danger (Red): `#EF4444` — absent stats, errors.
- Backgrounds: Light gray (`#F3F4F6`) for app, White (`#FFFFFF`) for cards.
- Text: Dark slate (`#1E293B`) for headings, gray (`#64748B`) for secondary.

## Components
- Sidebar: Fixed left. Yellow background for active state.
- Cards: White, `rounded-xl`, shadow-sm, generous padding.
- Buttons: Primary is Yellow with dark text.
- Avatars: Circular, dark background with initials.

## Screen Rules
- Login: Centered card, "Login as" dropdown, Yellow "Log In" button.
- Profile: Two columns. Left: Profile Info. Right: Attendance Calendar.
- Attendance Dashboard: 4 stat cards top, Weekly bar chart bottom left, Today donut chart bottom right. "Mark Attendance" button top right.
